# Tech Stack

## Frontend
- **React** with **TypeScript** — component-based UI with static type checking

## Backend
- **Node.js** — JavaScript runtime for the API server
- **Express** — HTTP framework for building REST API endpoints

## Database
- **PostgreSQL** — relational database for tickets, users, categories, and sessions

## ORM
- **Prisma** — type-safe database client and migration tool for PostgreSQL

## Authentication
- **Database sessions** — server-side sessions stored in PostgreSQL (no JWTs)

## Styling
- **Tailwind CSS** — utility-first CSS framework

## Email
- **SendGrid** or **Mailgun** — transactional email for sending replies and receiving inbound emails via webhook

## AI
- **Anthropic Claude API** — ticket classification, summaries, and suggested replies

## Deployment
- **Docker** — containerised deployment for both the app and the database
